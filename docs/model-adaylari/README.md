# Karakter modeli adayları

Bu ortamdan doğrudan indirilebilen (raw.githubusercontent.com üzerinden)
karakter modellerinin oyun motorunda alınmış görüntüleri. Model seçimi için
karşılaştırma amacıyla üretildi.

| Görüntü | Model | Animasyon | Modüler ekipman | Kaynak / lisans |
|---|---|---|---|---|
| 1-Knight | KayKit Knight | 73 klip (yürüme, koşma, 3 saldırı, blok, darbe, ölüm, zıplama) | miğfer, pelerin, kılıç, kalkan | KayKit Adventurers, CC0 |
| 2-Barbarian | KayKit Barbarian | 73 klip (Knight ile aynı iskelet ve set) | başlık, pelerin, balta, kalkan | KayKit Adventurers, CC0 |
| 3-Soldier | three.js Soldier | 3 klip (idle, walk, run) | yok, tek parça | mrdoob/three.js örnekleri |
| 4-Xbot | three.js Xbot | 7 klip (idle, walk, run + jestler) | yok, dokusuz manken | Mixamo / three.js örnekleri |
| 5-Michelle | three.js Michelle | 1 klip (samba dansı) | yok | Mixamo / three.js örnekleri |
| 6-Robot | RobotExpressive | 14 klip | yok | mrdoob/three.js örnekleri |
| 7-CesiumMan | Khronos CesiumMan | yok (test modeli) | yok | KhronosGroup/glTF-Sample-Assets |

Saldırı animasyonu yalnızca 1 ve 2'de var; ikisinin iskeleti ve klip seti
birebir aynı olduğu için birlikte kullanılabilirler (zırh takılıyken şövalye
gövdesi, çıkarınca barbarın çıplak gövdesi).

Quaternius, Sketchfab, Mixamo ve itch.io bu ortamdan erişilebilir değil;
oralardaki modeller repoya Release olarak yüklenerek getirilebiliyor.
